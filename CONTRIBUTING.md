# Contributing to Hulool Rifad

Thank you for helping build a reusable, open AI asset commons.

## Principles

- Prefer original, well-scoped assets over quantity.
- Keep content separate from the site application.
- Declare compatibility, licensing, and limitations honestly.
- Preserve lineage: forks and customized versions must name their parent.
- Never include secrets, private data, or copyrighted material without permission.

## Pull requests

1. Create a branch and add the asset plus registry record.
2. Run `python3 scripts/validate.py`.
3. Explain the use case, test cases, expected outputs, and license.
4. Keep changes focused; update docs when adding a new asset type.
5. Wait for CI to pass and respond to review feedback.

## Content checklist

- Unique stable ID, semantic version, author, source, license, and dates
- Clear inputs, outputs, constraints, and compatibility
- At least one example or test case for executable assets
- No API keys, credentials, personal information, or unlicensed media
